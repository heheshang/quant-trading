## 1. 页面概述与目标

### 1.1 页面定位

风控仪表盘是量化交易系统的核心监控页面，用于实时监控当日亏损、持仓限制、账户权益等关键风险指标，并在触发风控阈值时提供紧急平仓能力。

### 1.2 核心功能

- **当日亏损监控**：实时显示当日累计盈亏，支持设置亏损预警阈值
- **持仓限制管理**：展示各交易对持仓数量和持仓限额，支持手动调整
- **紧急全平功能**：一键平仓所有当前持仓，包含二次确认
- **风险指标看板**：账户权益、可用余额、保证金占用、风险率等
- **风控日志**：记录所有风控事件和操作历史

### 1.3 用户角色

- 管理员（Admin）：完整风控权限
- 交易员（Trader）：查看权限，紧急平仓需二次验证

## 3. 核心交互流程

### 3.1 当日亏损监控

1. 页面加载时调用 `GET /api/risk/daily-pnl` 获取当日盈亏数据
2. 亏损值与阈值对比：
   - `< 阈值80%`：正常显示
   - `>= 阈值80%`：黄色预警
   - `>= 阈值100%`：红色警告，触发通知
3. 数值变更时闪烁动画（2s）

### 3.2 持仓限制调整

1. 点击表格中某行的「调整限额」按钮
2. 弹出限额调整对话框
3. 输入新限额值（必须 >= 当前持仓）
4. 确认后调用 `PUT /api/risk/position-limit/:symbol`
5. 表格刷新更新

### 3.3 紧急全平流程

1. 点击「紧急全平」红色按钮
2. 弹出紧急平仓确认对话框：
   - 显示当前所有持仓汇总
   - 风险提示：「此操作将立即平仓所有仓位，无法撤销」
   - 输入验证码（管理员操作码）
3. 确认后调用 `POST /api/risk/emergency-close-all`
4. 显示执行结果（成功/失败）
5. 刷新持仓和账户数据

### 3.4 风控日志查看

1. 点击「风控日志」按钮
2. 展开侧滑抽屉显示完整日志列表
3. 支持按类型筛选（平仓/调整限额/报警）

## 4. 状态设计

### 4.1 加载状态

- 页面初始加载：骨架屏（Skeleton）
- 数据刷新：卡片区域 shimmer 效果
- 紧急操作执行中：按钮 loading + 禁止重复点击

### 4.2 空状态

- 无持仓时：卡片显示「暂无持仓」，全平按钮禁用
- 无风控日志：显示空状态插图 + 「暂无风控记录」

### 4.3 错误状态

- API 失败：Toast 提示 + 重试按钮
- 网络断开：顶部横幅「网络连接已断开」
- 权限不足：弹窗提示 + 返回上一页

### 4.4 状态颜色规则

| 状态 | 颜色 | 用途 |
|------|------|------|
| 正常 | `--color-success` (#10b981) | 盈利/安全 |
| 警告 | `--color-warning` (#f5a623) | 亏损预警 |
| 危险 | `--color-error` (#e5484d) | 触发风控/紧急 |
| 信息 | `--color-info` (#60a5fa) | 正常提示 |

## 5. API 调用说明

### 5.1 接口列表

| 方法 | 端点 | 描述 | 响应 |
|------|------|------|------|
| GET | `/api/risk/dashboard` | 获取风控仪表盘数据 | RiskDashboardResponse |
| GET | `/api/risk/daily-pnl` | 获取当日盈亏 | DailyPnlResponse |
| GET | `/api/risk/position-limits` | 获取持仓限额列表 | PositionLimit[] |
| PUT | `/api/risk/position-limit/:symbol` | 更新持仓限额 | SuccessResponse |
| POST | `/api/risk/emergency-close-all` | 紧急全平 | EmergencyCloseResponse |
| GET | `/api/risk/logs` | 获取风控日志 | RiskLog[] |

### 5.2 数据类型

```typescript
interface RiskDashboardData {
  daily_pnl: string              // 当日盈亏 Decimal
  daily_pnl_limit: string        // 当日亏损限额
  total_equity: string            // 账户总权益
  available_balance: string       // 可用余额
  margin_used: string             // 已用保证金
  margin_ratio: string            // 保证金率
  risk_level: 'safe' | 'warning' | 'danger'
  positions: PositionLimit[]
  logs: RiskLog[]
}

interface PositionLimit {
  symbol: string
  side: 'long' | 'short'
  current_quantity: string
  position_limit: string
  margin_used: string
}

interface RiskLog {
  id: string
  type: 'close' | 'limit_adjust' | 'alert' | 'emergency_close'
  message: string
  created_at: string
}
```

## 7. 响应式设计

### 7.1 断点

| 断点 | 宽度 | 布局 |
|------|------|------|
| Desktop | >= 1280px | 4列卡片 + 完整表格 |
| Laptop | 1024-1279px | 2x2 卡片 + 表格滚动 |
| Tablet | 768-1023px | 2列卡片 + 简化表格 |
| Mobile | < 768px | 单列卡片 + 卡片式持仓列表 |

- 卡片切换为纵向堆叠
- 表格列减少为：交易对/方向/持仓/限额/操作
- 紧急全平按钮固定在底部
