### 1.3 数据类型（Gherkin + ADR-010 对齐）

#### Order 类型

```typescript
export interface Order {
  order_id: string                          // UUID
  symbol: string                            // 交易对
  side: 'buy' | 'sell'                      // 方向
  order_type: 'limit' | 'market'             // 委托类型 (MVP: limit + market)
  price: string | null                      // 限价单 Decimal 字符串，市价单 null
  quantity: string                          // Decimal 字符串
  filled_quantity: string                   // Decimal 字符串
  avg_fill_price: string | null             // Decimal 字符串
  status: 'pending' | 'partial_filled' | 'filled' | 'cancelled' | 'expired' | 'rejected'
  mode: 'paper' | 'live'                    // 交易模式
  fee: string                               // Decimal 字符串
  time_in_force: 'GTC' | 'IOC' | 'FOK'     // 有效期
  strategy_id: string | null                // 策略信号下单
  created_at: string                        // ISO 8601
  updated_at: string                        // ISO 8601
}
```

#### Position 类型

```typescript
export interface Position {
  id: string
  symbol: string
  side: 'long' | 'short'
  quantity: string                          // Decimal
  available_quantity: string                // Decimal (扣除冻结)
  avg_entry_price: string                   // Decimal
  unrealized_pnl: string                    // Decimal
  realized_pnl: string                      // Decimal
  mode: 'paper' | 'live'
  created_at: string
  updated_at: string
}
```

#### Account 类型

```typescript
export interface Account {
  user_id: string
  balance: string                           // 可用余额
  frozen_balance: string                    // 冻结余额
  initial_balance: string                   // 初始资金
  total_pnl: string                         // 累计盈亏
  equity: string                            // 权益
  positions_count: number
  active_orders_count: number
}
```

#### Trade 类型

```typescript
export interface Trade {
  trade_id: string
  order_id: string
  symbol: string
  side: 'buy' | 'sell'
  price: string
  quantity: string
  fee: string
  is_maker: boolean
  created_at: string
}
```

#### CreateOrderRequest

```typescript
export interface CreateOrderRequest {
  symbol: string
  side: 'buy' | 'sell'
  order_type: 'limit' | 'market'
  price?: string                            // 限价单必填
  quantity: string
  time_in_force: 'GTC' | 'IOC' | 'FOK'
}
```

### 3.5 PriceInput（价格输入）

| 状态 | 样式 |
|------|------|
| 默认 | `--color-surface-elevated` 背景，`--color-border` 边框 1px |
| 聚焦 | `--color-accent` 边框 2px |
| 错误 | `--color-error` 边框 2px，下方显示错误信息 12px 红色 |
| 禁用 | opacity 0.4，cursor: not-allowed |

**快捷按钮：**
- 「市价」按钮：点击填入当前最优价
- 上下箭头按钮：步进 = 10^(-price_precision)

**校验规则（实时）：**

| 校验项 | 规则 | 错误信息 |
|--------|------|---------|
| 必填 | 限价单必填 | 「请输入委托价格」 |
| 正数 | > 0 | 「价格必须大于0」 |
| 精度 | ≤ price_precision 位小数 | 「价格精度不超过 N 位小数」 |
| 偏离 > 10% | 价格偏离当前市价 | 显示 PriceDeviationWarning |
| 偏离 > 100% | — | 「委托价格偏离当前市场价较大(100%)，是否确认提交？」 |

### 3.6 QuantityInput（数量输入）

**尺寸**: 同 PriceInput，高度 40px

**校验规则（实时）：**

| 校验项 | 规则 | 错误信息 |
|--------|------|---------|
| 必填 | 必填 | 「请输入委托数量」 |
| 正数 | > 0 | 「数量必须大于0」 |
| 精度 | ≤ quantity_precision 位小数 | 「数量精度不超过 N 位小数」 |
| 最小量 | ≥ min_quantity | 「最小下单数量为 {min}」 |
