### 2.2 侧边栏导航 (Sidebar)

**规格：**
- 宽度：`240px`（桌面端固定）
- 背景：`--color-bg`
- 右边框：`1px solid --color-border`
- 顶部 Logo：`48px` 高，内容区域垂直居中

**导航项规格：**
- 高度：`40px`
- 内边距：`0 16px`
- 圆角：`6px`（左右外边距 `8px`）
- 字号：`14px`，字重 `510`
- 图标：左侧 `20px` 图标，图标与文字间距 `12px`

**导航项状态：**

| 状态 | 背景 | 文字色 | 图标色 |
|------|------|--------|--------|

**导航项列表：**

**移动端（<768px）：**
- 侧栏折叠为底部汉堡菜单
- 展开时覆盖层 + 从左侧滑出的抽屉（240px）
- 遮罩层背景：`rgba(0,0,0,0.5)`

### 2.3 顶部栏 (Header)

**规格：**
- 高度：`48px`
- 背景：`--color-bg`
- 下边框：`1px solid --color-border`
- 内边距：`0 24px`
- 左侧：面包屑导航
- 右侧：暗色/亮色切换按钮 + 用户头像下拉

**面包屑导航：**
- 格式：`主页 > 一级 > 当前`
- 字号：`13px`
- 字重：上一级 `400`，当前级 `510`

**主题切换按钮：**

- 圆角：`6px`
- 默认背景：透明，图标色 `--color-text-tertiary`

- 点击切换并保存到 localStorage

**用户头像下拉：**
- 头像：`28x28px`，圆角 `6px`，背景色 `var(--color-accent)`，文字白色 `13px` 首字母

|           |   [登录按钮]                      |            |
|           |   --- 或使用 ---                  |            |
|           |   [SSO / Google 登录]             |            |
|           |                                  |            |
|           +----------------------------------+            |
|                                                          |

+----------------------------------------------------------+

### 3.2 页面规格

- 全屏居中，背景 `--color-bg`
- 登录卡片：宽度 `400px`，居中 `margin: auto`
- Logo + 产品名：上方 `48px` 间距，`[图标32x32] 量化交易系统`

### 3.3 登录表单

| 字段 | 组件 | 规格 |
|------|------|------|
| 邮箱 | Input (text) | 全宽，placeholder"请输入邮箱地址" |
| 密码 | Input (password) | 全宽，placeholder"请输入密码"，右侧眼睛图标切换可见性 |
| 记住我 | Checkbox | 左对齐，"记住登录状态" |
| 忘记密码 | Text link | 右对齐，字号 `13px`，色 `--color-accent` |
| 登录按钮 | Button (primary) | 全宽，高度 `40px`，"登录" |
| SSO 登录 | Button (secondary) | 全宽，高度 `40px`，"使用 SSO 登录" |

### 3.4 Register 表单（Tab切换）

在登录卡片中通过 Tab 切换（两个 Tab：登录 / 注册）：

| 字段 | 组件 | 规格 |
|------|------|------|
| 昵称 | Input (text) | 全宽，placeholder"请输入昵称" |
| 邮箱 | Input (text) | 全宽，placeholder"请输入邮箱地址" |
| 验证码 | Input + 按钮 | 左侧输入框 + 右侧"获取验证码"按钮 |
| 密码 | Input (password) | 全宽，placeholder"请设置密码（至少8位）" |
| 确认密码 | Input (password) | 全宽，placeholder"请再次输入密码" |
| 注册按钮 | Button (primary) | 全宽，"注册" |

### 3.5 状态矩阵

#### 登录状态

| 状态 | 触发条件 | 视觉表现 |
|------|---------|---------|
| **默认** | 页面初始加载 | 表单空白，登录按钮 disabled（灰色 `#62666d`） |
| **填空中** | 任意字段输入 | 登录按钮 enabled |
| **验证失败** | 邮箱格式错误 | Input 红色边框 `--color-error`，下方红色提示"请输入有效的邮箱地址" |
| **验证失败** | 密码 <6位 | Input 红色边框，提示"密码至少6位" |
| **密码不一致** | 注册页两次密码不同 | 确认密码框红色边框，提示"两次密码不一致" |
| **加载中** | 点击登录/注册后 | 按钮显示 Loading spinner，文字不变；禁用状态；Input 全部禁用 |
| **错误** | 服务器返回错误 | Input 上方 Toast 显示错误信息（红色背景 `--color-error-bg`） |
| **成功** | 登录成功 | 跳转到仪表盘 |
| **限流** | 5次失败后 | Toast 提示"登录尝试过于频繁，请60秒后再试"，倒计时 |
| **网络断开** | 请求失败 | Toast "网络连接失败，请检查网络" |
| **会话过期** | Token 失效 | 自动跳转到登录页，Toast "登录已过期，请重新登录" |

#### 验证码倒计时

| 阶段 | 按钮状态 | 显示文字 |
|------|---------|---------|
| 初始 | Enabled | "获取验证码" |
| 倒计时中 | Disabled | "60s" → "59s" → ... → "1s" |
| 可重新获取 | Enabled | "重新获取" |

### 3.6 空状态 / 边界情况

- 无单独的空状态（登录页本身是空起始页）
- 邮箱/密码自动填充：浏览器自动填充时，Input 背景变为系统自动填充色（维持暗色兼容）
- SSO 配置缺失：隐藏"使用SSO登录"按钮

### 4.2 StatCard 组件规格

**尺寸：**
- 宽度：自适应（`calc(25% - 12px)`，间距 `16px`）
- 高度：`112px`
- 背景：`--color-surface`
- 圆角：`8px`
- 边框：`1px solid --color-border`
- 内边距：`20px`

**内容布局：**
```
+----------------------------------------+
| [图标]  标签                            |
|         数值 (大号)                      |
|         涨跌指示 ▼/▲ + 变化率           |
+----------------------------------------+
```

| 元素 | 规格 |
|------|------|
| 图标 | 18px，色 `--color-text-tertiary`，与文字间距 `8px` |
| 标签 | 13px，色 `--color-text-tertiary`，字重 400 |
| 数值 | 28px，色 `--color-text-primary`，字重 600，等宽字体 |
| 涨跌指示 | 12px，涨 `--color-buy` ▲，跌 `--color-sell` ▼，平 `--color-stat-neutral` — |

**StatCard 状态矩阵：**

| 状态 | 触发条件 | 视觉表现 |
|------|---------|---------|
| **默认** | 正常数据 | 正常显示数值 |
| **加载中** | API 加载 | 数值区域显示 Skeleton（宽 `80px`，高 `28px`） |
| **加载失败** | API 异常 | 数值显示 `--`，涨跌隐藏；hover 提示"加载失败，点击重试" |
| **空数据** | 新用户无数据 | 数值 `0.00`，涨跌 `--` |
| **大数值** | >1亿 | `1.23亿`，tooltip 显示完整数值 `123,456,789.00` |

### 4.3 PnLChart（净值曲线组件）

**规格：**
- 容器高度：`320px`
- 背景：`--color-surface`
- 圆角：`8px`
- 边框：`1px solid --color-border`
- 内边距：`20px`
- 基于 ECharts 面积图

**图表配置：**
- X轴：日期（可缩放时间范围：1周/1月/3月/6月/1年/全部）
- Y轴：净值（自动缩放）
- 面积填充：渐变 `rgba(113,112,255,0.2)` → `rgba(113,112,255,0.02)`
- 线条色：`--color-accent`，宽度 `2px`
- 基准线（若净值为1.0起始）：虚线 `rgba(255,255,255,0.1)`
- 十字准线：交互 hover，显示日期 + 净值
- Tooltip：`[2026-05-12] 净值：123,456.78 | 日收益：+1.23%`

**时间范围切换器：**
- 位置：图表右上角
- 样式：pill 按钮组（同 FilterPill 样式）
- 选项：1周 | 1月 | 3月 | 6月 | 1年 | 全部
- 当前选中：--color-accent 色

**状态矩阵：**

| 状态 | 触发条件 | 视觉表现 |
|------|---------|---------|
| **默认** | 正常 | 完整绘制 |
| **加载中** | 数据请求中 | 显示 Skeleton 骨架屏（面积图轮廓闪烁） |
| **加载失败** | API异常 | 居中显示"数据加载失败，点击重试"图标链接 |
| **空数据** | 新用户 | 居中显示"暂无交易数据，开始您的第一笔交易" + [开始交易] 按钮 |
| **数据不足** | <5个点 | 正常绘制但显示提示"数据点较少，仅供参考" |

## 15. 暗色/亮色模式切换

### 15.1 切换机制

- 默认跟随系统 `prefers-color-scheme`
- 用户手动切换后保存到 `localStorage('theme')`
- 切换动画：`transition: background-color 0.3s ease, color 0.3s ease`

### 15.2 各页面模式差异

| 页面 | 暗色模式 | 亮色模式 |
|------|---------|---------|
| 所有 | 如上述定义 | 使用对应的亮色 token 值 |
| K线图 | 深色背景 `#050607` | 浅色背景 `#f0f0f0` |
| 深度图 | 深色背景 | 浅色背景 |
| ECharts 图表 | 暗色主题 `chalk` | 亮色主题 `light` |
| Lightweight Charts | 暗色配置 `dark` | 亮色配置 `light` |

### 15.3 亮色模式特殊处理

| 元素 | 亮色模式调整 |
|------|-------------|
| 图表网格 | 从半透明白改为半透明黑 |
| 卡片阴影 | 从 `none` 改为 `0 1px 3px rgba(0,0,0,0.06)` |
| 输入框边框 | 从半透明白改为半透明黑 |
| 文字色 | 从浅色变为深色 |
| 价格涨跌色 | 保持 `--color-buy` / `--color-sell` 但调亮 |
| 悬停背景 | 从白底改为黑底半透明 |
