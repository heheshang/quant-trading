## 1. 设计系统总览

### 1.1 设计基调

- **暗色优先**: 以近黑色 (`#08090a`) 为画布，信息从黑暗中浮现
- **数据密集**: 金融数据展示优先，信息密度高但层次分明
- **品牌色**: 靛蓝-紫色系 (`#5e6ad2` ~ `#7170ff`)，用于交互元素和品牌标识
- **涨跌色**: 红涨绿跌 (中国金融市场惯例)
  - 涨: `#eb4d5c` (中国红)
  - 跌: `#26a69a` (翡翠绿)
  - 平: `#8a8f98` (中性灰)
- **排版**: Inter Variable 为主，等宽字体用于数字/代码

### 3.3 交互逻辑

1. **标签切换**: 点击"登录"/"注册"标签 → 表单切换动画 (向右滑出/滑入 300ms ease)
2. **账户验证**: 失焦时即时验证格式 → 合法显示 success 图标 / 非法显示 error + 提示
3. **密码可见**: 点击眼睛图标切换 `type="text/password"`，图标同步切换
4. **登录 loading**: 点击登录 → Button 显示 loading 旋转 → 成功跳转 / 失败显示错误提示
5. **注册验证码**: 点击发送 → 按钮禁用 + 60s 倒计时 → 到达后恢复
6. **密码强度**: 实时检测并显示颜色变化 (红 < 黄 < 绿)
7. **响应式**: 375px 品牌区隐藏，表单占全宽

### 3.4 状态矩阵

### 8.3 交互逻辑

1. **方向切换**: 点击"做多"/"做空" → 大按钮切换样式 (做多红底/做空绿底) + 下单面板提示更新
2. **价格联动（限价单）**: 点击盘口报价 (买一/卖一) → 价格输入框自动填入
3. **数量百分比**: 点击 25%/50%/75%/100% → 根据可用余额自动计算数量
4. **下单确认**: 点击买入/卖出 → 确认弹窗 (显示交易详情) → 提交 → toast 成功/失败
5. **市价单**: 切换到市价单 → 价格输入框 disabled + 显示"市价"
6. **止损单**: 切换到止损单 → 多出"触发价格"输入框
7. **撤单**: 点击撤单 → 二次确认 → 请求 → toast
8. **键盘快捷键**: 按 `→` 切换买入/卖出, `Enter` 提交订单
9. **风控检查**: 提交前检查 (余额不足 → 提示; 超过风控阈值 → 阻止)

## 11. 全局交互规则

### 11.1 动效规范

| 场景 | 属性 | 持续时间 | 缓动函数 |
|------|------|----------|----------|
| hover 状态 | background-color / opacity | 150ms | ease |
| 页面切换 | opacity / transform | 200ms | ease-in-out |
| 面板展开 | height / max-height | 300ms | cubic-bezier(0.4,0,0.2,1) |
| 弹窗出现 | opacity + scale(0.95→1) | 200ms | ease-out |
| Toast 出现 | translateY(-20→0) + opacity | 300ms | ease-out |
| 图表重绘 | — | 300ms | — |
| 骨架屏脉冲 | opacity | 1.5s loop | ease-in-out |
| 下拉菜单 | opacity + translateY(-4→0) | 150ms | ease |
| 数字滚动 | — | 500ms | ease-out |

### 11.2 键盘快捷键

| 快捷键 | 全局 | 行情页 | 交易页 |
|--------|------|--------|--------|
| `Ctrl+K` | 命令面板 | — | — |
| `→ / ←` | — | — | 切换做多/做空 |
| `Enter` | — | — | 提交订单 |
| `Esc` | 关闭弹窗 | — | 取消 |
| `F1` | — | 切换图表类型 | — |
| `,` | — | — | 价格-10 |
| `.` | — | — | 价格+10 |

### 11.3 数据刷新策略

| 数据类型 | 刷新方式 | 频率 |
|----------|----------|------|
| 行情价格 | WebSocket | 实时 (100-500ms) |
| K线数据 | REST + WS | 按周期 |
| 持仓/订单 | WebSocket | 实时 |
| 资产余额 | REST 轮询 | 3s |
| 策略状态 | REST 轮询 | 5s |
| 回测结果 | REST 轮询 | 2s (回测中) |
| 系统配置 | REST (懒加载) | 按需 |

### 11.4 错误处理规范

| 错误类型 | 用户提示 | 恢复方式 |
|----------|----------|----------|
| 网络断开 | toast "网络连接断开" | 自动重连 (3次) |
| API 超时 | toast "请求超时，请重试" | 手动重试 |
| 余额不足 | Inline error "可用余额不足" | 关闭提示 |
| 无权限 | toast "无权限执行该操作" | — |
| 服务器错误 | toast "服务器繁忙，请稍后重试" | 自动重试 1次 |
| 表单验证 | 字段下方 inline error | 修改内容 |

### 11.5 空状态/缺省态

每个列表/表格需要覆盖以下状态:
1. **加载中**: Skeleton 骨架屏 (表单渲染占位)
2. **空数据**: 简单 SVG 插画 + "暂无 XX" 文字 + (可选)操作引导按钮
3. **加载失败**: 错误图标 + "加载失败" + 重试按钮
4. **数据过滤为空**: "未找到匹配结果" + 清除筛选按钮
