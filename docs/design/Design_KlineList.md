## 1. 页面概述与目标

### 1.1 页面定位

K线数据列表页面用于展示和管理历史K线数据，支持多维度筛选、分页浏览和数据质量监控。用户可查看各交易对的K线历史记录。

### 1.2 核心功能

- **K线列表展示**：表格展示K线数据（时间/交易对/周期/开盘/收盘/最高/最低/成交量）
- **多维度筛选**：交易对、交易所、周期、日期范围
- **分页浏览**：支持分页和每页条数切换
- **K线图表**：点击查看弹出迷你K线图表
- **数据质量标记**：异常数据红色高亮

### 1.3 数据周期

支持周期：1m / 5m / 15m / 30m / 1h / 4h / 1d / 1w

## 3. 核心交互流程

### 3.1 筛选流程

1. 选择交易对（必选）
2. 选择交易所
3. 选择周期
4. 选择日期范围
5. 点击「搜索」或 300ms 自动搜索
6. 调用 `GET /api/klines` + 筛选参数
7. 刷新表格

### 3.2 查看K线图表

1. 点击表格行「查看图表」按钮
2. 弹出对话框显示 ECharts K线图
3. 支持缩放和平移
4. 关闭弹窗返回列表

### 3.3 异常数据标记

1. 数据缺失或明显异常时行高亮
2. 异常原因：
   - 成交量为0
   - 收盘价与开盘价差超过50%
   - 数据缺失（时间不连续）
3. 点击行可查看异常详情

### 3.4 分页流程

1. 选择每页条数（20/50/100）
2. 切换页码
3. URL 参数同步（?page=1&size=50）
4. 支持浏览器前进/后退

## 4. 状态设计

### 4.1 加载状态

- 页面初始：骨架屏表格
- 筛选加载：表格区域 shimmer
- 图表加载：图表占位 + spinner

### 4.2 空状态

- 无数据：「暂无K线数据，请先导入」
- 筛选无结果：「未找到匹配的K线数据」

### 4.3 错误状态

- 加载失败：表格区域错误提示 + 重试按钮
- 网络错误：Toast 提示

### 4.4 表格状态

| 状态 | 样式 |
|------|------|
| 正常 | 默认 |
| 异常 | 行背景 `--color-error-bg` + 红色文字 |
| 选中 | 行背景 `--color-accent-bg` |

### 4.5 涨跌颜色

| 状态 | 颜色 |
|------|------|
| 涨（收 > 开） | `--color-success` |
| 跌（收 < 开） | `--color-error` |
| 平（收 = 开） | `--color-text-secondary` |

## 5. API 调用说明

### 5.1 接口列表

| 方法 | 端点 | 描述 |
|------|------|------|
| GET | `/api/klines` | 获取K线列表（分页+筛选） |
| GET | `/api/klines/:id` | 获取单条K线 |
| GET | `/api/klines/chart/:id` | 获取K线图表数据 |
| GET | `/api/klines/stats` | 获取数据统计 |
| GET | `/api/symbols` | 获取交易对列表 |
| GET | `/api/exchanges` | 获取交易所列表 |

### 5.2 数据类型

```typescript
interface Kline {
  id: string
  symbol: string
  exchange: 'binance' | 'okx' | 'gateio' | 'bybit'
  interval: '1m' | '5m' | '15m' | '30m' | '1h' | '4h' | '1d' | '1w'
  open_time: string
  close_time: string
  open: string
  high: string
  low: string
  close: string
  volume: string
  quote_volume: string
  is_anomaly: boolean
  anomaly_reason: string | null
  created_at: string
}

interface KlineStats {
  total_count: number
  anomaly_count: number
  completeness: number        // 百分比
  by_exchange: Record<string, number>
  by_interval: Record<string, number>
}

interface KlineQueryParams {
  symbol?: string
  exchange?: string
  interval?: string
  start_date?: string
  end_date?: string
  is_anomaly?: boolean
  page?: number
  size?: number
}
```
