Quant Trading System — Architecture Overview v1.0

核心技术栈

  • 前端: Vue 3 + Composition API + TypeScript strict
  • UI: Element Plus · 图表: ECharts + Lightweight-charts
  • 后端: Rust 2024 + Axum · ORM: SeaORM/SQLx
  • 数据库: PostgreSQL 16 (主) + Redis 7 (缓存/PubSub)
  • 实时通信: WebSocket (tokio-tungstenite)
  • 容器化: Docker + docker-compose

核心数据流

  • 行情: Exchange → Market Data Collector → Redis Cache → WS Push
  • 策略: Strategy Engine ↔ Redis Pub/Sub ↔ Market Data Service
  • 交易: Strategy Engine → Risk Manager → Order Service → Exchange
  • 回测: Backtest Runner → Historical DB → Results → PostgreSQL
  • 用户: Client → REST API → Auth Middleware → Handlers → DB

架构特性

  • 水平扩展: 无状态 REST handlers, 可多实例部署
  • 策略隔离: 每个策略独立 tokio task, 带超时/内存沙箱
  • 实时性: WebSocket 推送延迟 <500ms
  • 高可用: Redis哨兵, PG流复制, 降级策略
  • 安全: JWT 15min + refresh 7d + jti 黑名单
  • 限流: 100 req/min per user
