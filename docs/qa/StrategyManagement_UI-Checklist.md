## P0：功能缺失 / 核心交互错误

### P0-1： StrategiesView 列表使用 TABLE 而非 CARD GRID
- **规格（6.1 布局）：** 三列网格卡片布局，每卡片显示策略名称/描述/收益率+夏普率+最大回撤+交易次数/标签/上次运行时间
- **实际实现：** el-table 列表，每行仅显示策略名称/描述+交易对+周期+模板类型+状态
- **影响：** 用户无法快速浏览策略绩效，核心视觉设计未落地

### P0-2： StrategiesView 表格缺少绩效指标列
- **规格（StrategyCard）：** 收益率/夏普率/最大回撤/交易次数 四个指标必须显示
- **实际实现：** 表格中无任何绩效指标列
- **影响：** 策略概览信息严重不足

### P0-3： StrategyCreateView 表单缺少策略类型字段
- **规格（6.3 表单字段）：** 策略类型 Select（趋势跟踪/均值回归/网格交易/套利/自定义）必填
- **实际实现：** 基本信息表单仅有 name/symbol/timeframe，无策略类型字段
- **影响：** 无法按策略类型分类管理

### P0-4： StrategyCreateView 表单缺少策略描述字段
- **规格（6.3 表单字段）：** 策略描述 Textarea，最大500字符，非必填
- **实际实现：** 基本信息表单无描述字段
- **影响：** 用户无法填写策略说明

### P0-5： StrategyCreateView 表单缺少风控参数组
- **规格（6.3 表单字段）：** 最大持仓/止损比例/止盈比例 三个风控字段
- **实际实现：** 无风控参数配置区域
- **影响：** 核心风控配置缺失

### P0-6： StrategyCreateView 表单缺少策略文件上传
- **规格（6.3 表单字段）：** 策略文件上传，支持 .py .js
- **实际实现：** 无上传组件
- **影响：** 无法上传自定义策略代码

### P0-7： StrategiesView 筛选器缺少「已归档」状态
- **规格（6.1 FilterPills）：** [全部] [运行中] [已暂停] [草稿] [已归档]
- **实际实现：** [全部] [草稿] [运行中] [已暂停] [已停止]（无「已归档」，多了「已停止」）
- **影响：** 状态机不完整

### P0-8： StrategiesView 删除确认框不显示策略名称
- **规格（6.4 确认删除模态框）：** 正文必须包含策略名称「确定要删除「策略名称」吗？」
- **实际实现：** `确定要删除选中的 {{ deleteTargets.length }} 个策略吗？此操作不可撤销。` — 通用提示，无策略名称
- **影响：** 误删风险

## P1：样式 / 文案不一致

### P1-1： StrategyTemplateView 按钮文案应为「使用此模板」
- **规格：** 模板卡片底部按钮「使用此模板」
- **实际实现：** `使用此模板` ✓（一致）

### P1-2： StrategiesView 状态 DOT 尺寸偏大
- **规格（6.2 StrategyCard）：** 状态点 6px 圆点
- **实际实现：** `.status-dot { width: 8px; height: 8px; }` — 8px
- **影响：** 轻微视觉偏差

### P1-3： StrategiesView 操作列宽度超出规格
- **规格：** 操作列宽度「80px align:center fixed:right」
- **实际实现：** `width="80"` ✓ 一致

### P1-4： StrategyCreateView 按钮文案不一致
- **规格（6.3 表单状态）：** 保存成功 Toast「策略保存成功」
- **实际实现：** 待确认（需运行验证）
- **建议：** 统一使用「策略保存成功」

### P1-5： StrategyCreateView 步骤条文案
- **规格（6.3）：** 新建/编辑策略应为 3 步流程
- **实际实现：** StepIndicator 存在 ✓（选择模板 → 配置参数 → 确认完成）
- **状态：** 一致

## P2：优化建议

### P2-1： StrategiesView 批量操作栏缺少「归档」选项
- **建议：** 已停止策略可归档，而非只能删除

### P2-2： StrategiesView 批量操作栏缺少「克隆」选项
- **建议：** 批量克隆功能提升效率

### P2-3： StrategiesView 应显示「上次运行时间」
- **规格（StrategyCard）：** 上次运行: 5分钟前
- **实际实现：** 无此字段
- **建议：** 在表格中添加「上次运行」列

### P2-4： StrategiesView 模板类型标签色值需对齐
- **规格（StrategyCard 标签）：** 背景 `rgba(255,255,255,0.04)`，文字 `--color-text-tertiary`
- **实际实现：** 使用 el-tag `effect="plain"` + `getCategoryTagType`
- **建议：** 对齐色值规范

### P2-5： StrategyCreateView 缺少草稿自动保存提示
- **规格（6.3 表单状态）：** 编辑中每30秒「已保存草稿」右上角提示
- **实际实现：** 无自动保存逻辑
- **建议：** 添加 autosave 机制和 UI 提示

### P2-6： StrategyCreateView 应禁用运行中策略的 symbol/timeframe
- **规格（6.3 表单状态）：** 编辑已有时 symbol/timeframe 应禁用
- **实际实现：** `isEdit` 时 `symbol/timeframe` 有 `disabled` ✓
- **状态：** 一致

### P2-7： StrategiesView 建议支持导出功能
- **规格（走查范围）：** 导入/导出功能
- **实际实现：** 无导入/导出按钮
- **建议：** 在列表页添加导出按钮

### P2-8： StrategyTemplateView 缺少模板使用量/作者信息
- **规格（StrategyCard）：** 底部显示模板使用量、作者
- **实际实现：** 仅显示分类标签和参数数量
- **建议：** 扩展元数据

### P2-9： 策略卡片筛选器选中态可加强对比度
- **规格：** 活跃态背景 `--color-sidebar-active`，accent 颜色
- **实际实现：** `background: var(--color-accent)` 配合 `border-color: var(--color-accent)`
- **状态：** 基本一致
