## P1 检查项

### ✅ 边界清晰（15分）
**标准：明确不做什么**

- ❌ 不实现模型训练流水线（训练由外部 Python 服务独立完成）
- ❌ 不提供模型可视化训练过程（TensorBoard等）
- ❌ 不对接实时交易所订单簿推送（仅用回测/模拟盘数据）
- ❌ 不替代现有规则策略（AI信号作为增强输入）
- ❌ 不支持多模型 ensemble 自动搜索
- ✅ Rust 侧特征工程可在无 Python 环境独立运行（feature_engine.rs）
- ✅ AI 服务不可用时降级为 neutral 信号（概率 0.5）

**得分：15/15 ✅**

---

### ✅ 接口契约清晰（15分）
**标准：Rust 后端 ↔ Python 模型服务 API 明确**

| 端点 | 方法 | 输入 | 输出 |
|------|------|------|------|
| `/health` | GET | — | `{ "status": "ok" }` |
| `/predict/price_direction` | POST | `{ "features": [...], "model_version": "v1" }` | `{ "direction": "up", "prob": 0.72 }` |
| `/predict/sentiment` | POST | `{ "orderbook": {...} }` | `{ "score": 0.65, "label": "bullish" }` |
| `/models` | GET | — | `{ "versions": ["v1", "v2"] }` |

- **服务地址**: `AI_MODEL_SERVICE_URL` 环境变量配置
- **超时处理**: 2s 超时 → 降级 signal
- **通信协议**: REST JSON

**得分：15/15 ✅**
